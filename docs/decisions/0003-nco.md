# 0003: NCO as a phase accumulator with a quarter-wave sine table

## Context

The DDC mixes the signal down from the 100–250 kHz tuning offset (CLAUDE.md §2.3) and will carry Doppler
pre-correction (§3), so the NCO runs at arbitrary tuning words, not just one frequency. Its spurs mix into the
signal band. The input is 8-bit unsigned I/Q, about 48 dB of dynamic range, so spurs need to sit well under that.

## Options considered

| Option | Spurs | Resources | Notes |
|---|---|---|---|
| Phase accumulator + quarter-wave table, 12-bit phase, s16 amplitude | ≈ −72 dBc, from phase truncation | 1,024 × 16 bits: one BRAM18, or distributed ROM | Single-cycle lookup; simple to verify exactly |
| Same, full-wave table | Same | 4× the table | No benefit over quadrant mirroring |
| CORDIC, 16 iterations | Limited by iteration count and width; comparable at 16 bits | ~16 pipeline stages of adders, no BRAM | More latency and logic; harder to make bit-exact against a simple model |
| Table + phase dithering | Spurs spread into a noise floor | Adds an LFSR | Not needed at 72 dB against an 8-bit input |

## Decision

A 32-bit phase accumulator; the top 12 bits address a 1,024-entry quarter-wave table of s16 sines, sampled half a
step off zero (θ = 2π(k + 0.5)/4096) so the four quadrants mirror with no special case at the boundaries.

## Consequences

- 150 kHz is exactly 600·2²⁰ in a 32-bit accumulator, so at the default tuning there is no phase truncation at all.
  Any Doppler correction moves the word off that, so the design is judged on arbitrary words.
- The table is one BRAM18 or a distributed ROM; to be decided at synthesis.

## Measured evidence

`data/results/ddc_nco_sfdr.csv` (`python -m analysis.ddc_fixed_study`): across 64 random tuning words, SFDR is
71.6–72.8 dB, against the −6.02·12 ≈ −72 dB phase-truncation estimate. The 150 kHz word reads 109.9 dB, from
amplitude quantization alone. `model/tests/test_ddc_fixed.py` checks every output against the ideal phasor exactly
and requires SFDR above 60 dB, 12 dB under the 8-bit input's dynamic range.
