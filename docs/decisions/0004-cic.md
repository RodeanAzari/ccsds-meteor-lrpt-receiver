# 0004: CIC decimation by 4, order 3, then a 31-tap compensation FIR

## Context

The DDC takes 1.024 MS/s down to 256 kS/s, 3.56 samples per symbol (CLAUDE.md §3). The signal occupies ±54 kHz
(72 ksym/s, roll-off 0.5) plus Doppler (±3.4 kHz) and TCXO offset. The decimation must not alias energy into that
band, and the passband droop must be undone before the matched filter.

## Options considered

| Option | Resources | Notes |
|---|---|---|
| CIC ÷4, order 3, M = 1, + 31-tap droop FIR at 256 kS/s | 3 integrators + 3 combs at 22 bits, no multipliers; FIR: 31 MACs per output at 256 kS/s | One multiplier time-shared covers the FIR at a ~100 MHz core clock |
| Polyphase FIR ÷4 alone | Long filter at 1.024 MS/s | More multipliers for the same rejection; no clear benefit at R = 4 |
| CIC order 4 or 5 | 24- or 26-bit registers | More droop to correct; order 3 already decodes as well as the float model |
| Two half-band stages ÷2 ÷2 | Two FIRs | Cleaner response, more multipliers; not needed |

The float model (`model/receiver.py`) already used CIC ÷4, order 3, plus this FIR, and decodes every reachable frame
from 2.5 dB up (`data/results/fer_full_chain.csv`).

## Decision

CIC ÷4, order 3, differential delay 1, registers of 16 + 3·log₂4 = 22 bits (Hogenauer), output gain 64 removed by an
exact 6-bit rounded shift. Then a 31-tap inverse-droop FIR (`comp_fir_taps()`), taps s18 with 17 fraction bits.

## Consequences

- Integrators wrap by design; the comb output is still exact because the registers are the full Hogenauer width.
  An undersized register would wrap silently (CLAUDE.md §12), so a test shows that one bit fewer breaks it.
- The ratio is fixed at 4; `ddc_fixed()` refuses any other `RxConfig.decimation` or `cic_order`.

## Measured evidence

`data/results/ddc_fixed_chain.csv` (`python -m analysis.ddc_fixed_study`): with the bit-true DDC, the receiver
decodes the same frames as with the float DDC at every Eb/N0 from 2 to 8 dB, with soft-symbol SNR within 0.01 dB.
`model/tests/test_ddc_fixed.py` checks the CIC bit-exact against direct convolution at full scale.
